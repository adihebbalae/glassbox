Glassbox bug zoo

Each linked page seeds one or more known bug classes (see the HTML comments in each).

  • errors — console error, unhandled rejection, 404 asset, 500 fetch, hang
  • layout — overflow, contrast, zero-size, occlusion, broken image, no-a11y-name, dead button, CLS
  • overflow-vw — horizontal overflow by exactly the scrollbar gutter (100vw); invisible to a browser launched with --hide-scrollbars
  • dark — dark-theme-only contrast bug
  • dialog — native confirm on click
  • sourcemap — minified throw that remaps to original.ts
  • debug — named handlers, dead button, overridden white-on-white, unused CSS
  • hydrate — simulated Astro island, 800ms; ?stuck=1 never hydrates
  • clean — no seeded bugs (false-positive check)
